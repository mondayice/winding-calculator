公式与推导（点开查看）
  1. 每层匝数 N = ⌊W / d⌋，层数 n = ⌊h / d⌋
  2. 第 k 层半径 rₖ = D₀/2 + (k − ½)d，各层周长成等差数列
  3. 理想密绕线长（等差数列求和）：L = π · N · n · (D₀ + n·d)
  4. 体积法（含填充系数 η）：L = 4η · W · h · (D₀ + h) / d²；理想密绕对应 η = π/4 ≈ 0.785，等圆堆积理论极限 π/√12 ≈ 0.907
  5. 反算：解二次方程 h² + D₀·h − L·d²/(4ηW) = 0 得连续槽深，再取最大整数层 n 使 4η·N·n·(D₀ + n·d) ≤ L，占用槽深 = n·d
  6. 浮点精度：取整前先按 12 位有效数字规整——否则 0.9/0.3 = 2.999…96，⌊ ⌋ 会少算一层
  7. 每匝实为螺旋线，长度仅多 O((d/2πr)²)，可忽略

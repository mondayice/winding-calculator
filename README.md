# 绕线计算器

一个零依赖的单页计算器：**线往轮子上缠，能缠多长？** 或者反过来——**一卷线缠上去，会占多深的槽？**

基于分层密绕模型推导（等差数列求和 + 体积法交叉验证），内置浮点安全取整，双主题，纯本地运行。

## 功能特性

- **双模式互算**
  - 正算：由线径、轮直径、槽深、轮宽 → 可绕线长（含理想密绕与按填充系数 η 的工程估算）
  - 反算：由线长、线径、轮直径、轮宽 → 占用槽深（按整层数计），并给出剩余线长、距绕满下一层还差多少
- **直径口径可选**：轮的直径可指定为**槽底 D₀** 或**外缘 D外**（外缘口径自动按 D₀ = D外 − 2×槽深 换算；反算模式下会引导补充"最大槽深"并用示意图解释两个"槽深"的区别）
- **填充系数 η 可调**：预设理想密绕 0.785 / 手工乱绕 0.70 / 机器排线 0.85 / 精密排线 0.90，也可手填
- **浮点精度安全**：线径为毫米浮点数（如 0.3），直接 `⌊0.9/0.3⌋` 会因二进制误差得到 2 而非 3；取整前先按 12 位有效数字规整，杜绝少算一层
- **SVG 剖面实时可视化**：线圈截面、槽底/挡边、D₀/D₁/W 动态尺寸标注，绕出挡边时橙色虚线警示
- **深浅色主题**：跟随系统偏好，手动切换并记忆
- **无障碍与响应式**：键盘可达、焦点环、`aria-live` 结果播报；375px 手机 → 2K 宽屏均自适应
- **输入记忆**：参数自动存入 localStorage，下次打开自动恢复

## 使用场景：路亚绕线量估算（纺车轮 / 水滴轮）

线杯本质上就是一个线轴——本工具的四个输入正好对应线杯几何，适合在**备线、换线、垫底线**前估算用量。

**参数对应**

| 工具输入 | 线杯上的含义 | 怎么量 |
|---|---|---|
| 轮的直径（槽底 D₀） | 线杯轴径（线绕得最里的一圈） | 卡尺量芯轴直径 |
| 轮的直径（外缘 D外） | 杯口外沿直径 | 也可量外沿，配合挡边高度换算 |
| 槽深 h | 挡边高度（轴到杯口的径向高度） | 量轴表面到杯口沿的距离 |
| 轮宽 W | 绕线区宽度（线杯两侧壁间距） | 卡尺量绕线区 |
| 线径 d | 鱼线直径 | 见下表 |

**常见 PE 线径速查**（JAFS 标准，尼龙/碳素线各品牌差异大，以包装标注为准）

| PE 编号 | 0.6 | 0.8 | 1.0 | 1.5 | 2.0 | 2.5 | 3.0 | 4.0 |
|---|---|---|---|---|---|---|---|---|
| 线径 mm | 0.128 | 0.148 | 0.165 | 0.205 | 0.235 | 0.260 | 0.285 | 0.330 |

**纺车轮（纺车轮线杯呈锥形）**

- 锥形杯用圆柱模型是近似：建议取「轴径与杯口内径的平均值」作为 D₀，或直接量中段直径；锥度越明显误差越大，可将 η 取低一档（如 0.70）补偿。
- 经验上不绕满到杯沿：**距杯沿留 1~2 mm** 抛投顺滑、不易跳线。做法很简单——把槽深 h 减去 1~2 mm 再算。
- 常用"尼龙/碳素垫底 + PE 前段"：先用反算模式算出前段 PE 占多深，剩下的深度再算垫底线用量。

**水滴轮（直筒线杯，模型贴合度高）**

- 水滴轮线杯基本是直筒形，估算精度比纺车轮更好。
- 绕太满容易炸线（backlash），太浅损失抛投距离且拇指压线不好控制，同样建议**距杯沿 1~2 mm**。

**示例 1（正算）：水滴轮能绕多少 PE2.0？**

线杯轴径 25 mm、杯宽 14 mm、挡边高 6 mm：绕满约 **143 m**；留 1 mm 余量（按 h=5 mm 算）约 **117 m**——以留余量的为准备线。

**示例 2（反算）：100 m PE1.5 上杯占多深？垫多少底线？**

同一线杯（轴径 25、杯宽 14）：100 m PE1.5 绕 **16 层、占深 3.3 mm**；挡边 6 mm 留 1 mm 余量后，剩约 1.7 mm 给底线——垫 6 层尼龙 3 号约 **25 m**，先绕底线再接 PE。

**注意事项**

- 各品牌实际线径与标称有出入，绕线松紧（η）因人因设备而异，结果按**工程估算**看待；
- 打结、剪头、试抛损耗，备线建议在估算基础上多买 5~10%；
- 反过来也能用：输入厂商标称容量反推其口径假设，判断标称是"绕满"还是"留余量"。

## 数学模型

线一圈一层并排密绕，每层匝数与层数向下取整：

| 量 | 公式 |
|---|---|
| 每层匝数 | N = ⌊W / d⌋ |
| 层数 | n = ⌊h / d⌋ |
| 理想密绕线长 | L = π · N · n · (D₀ + n·d) |
| 工程估算（含填充系数） | L = 4η · W · h · (D₀ + h) / d² |
| 反算（解二次方程取整层） | h² + D₀·h − L·d²/(4ηW) = 0 |

- 理想密绕对应 η = π/4 ≈ 0.785（圆的方形排列密度），两种推导互相印证；
- 等圆堆积理论极限为 π/√12 ≈ 0.907（Thue 定理）；
- 每匝实为螺旋线，长度修正量为 O((d/2πr)²)，百万分之几，可忽略。

完整推导过程（建模、等差数列求和、体积法验证、修正项讨论、数值算例）见 [docs/绕线长度计算.md](docs/绕线长度计算.md)。

## 快速开始

无需构建、无需联网，三种方式任选：

```text
1. 双击 index.html                          —— 直接用（file:// 下同样工作）
2. 双击 启动计算器.bat                       —— 起本地服务并自动打开浏览器（需 Python 3）

```
